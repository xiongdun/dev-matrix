# code-review

## 描述

对代码变更进行审查，关注安全性、性能和可维护性。

## 触发条件

- 用户提交代码 diff
- 用户请求代码审查

## 执行步骤

1. 读取 diff 内容
2. 检查以下维度：
   - 安全漏洞（SQL 注入、XSS、硬编码密钥）
   - 性能问题（N+1 查询、内存泄漏）
   - 代码风格（命名规范、函数长度）
   - 测试覆盖（是否有对应测试）
3. 生成审查报告

## 输出格式

| 字段 | 说明 |
|------|------|
| score | 0-100 评分 |
| issues | 问题列表 |
| suggestions | 改进建议 |

## 约束

- 只审查用户指定的文件
- 不要修改代码，只提供建议
