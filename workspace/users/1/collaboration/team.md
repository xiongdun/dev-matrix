# 团队协作

## 共享范围

| 资源 | 共享方式 |
|------|----------|
| `_shared/` | 所有用户共享的 Agent 记忆 |
| `knowledge/` | 可选共享 |
| `templates/` | 可选共享 |
| `rules/` | 可选共享 |
| `memory/` | 私有 |
| `soul.md` | 私有 |
| `skill/` | 私有 |

## 协作规则

- 项目记忆 `projects/` 按项目 ID 共享，所有参与该项目的用户可读写
- 个人记忆 `memory/` 和 `soul.md` 仅本人可见
- `_shared/` 目录由管理员维护，所有 Agent 共享
