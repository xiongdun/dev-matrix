# Agent 共享记忆 — business_analyst

## 角色知识

- **需求分析模板**: 标准需求分析应包含：
  1. 功能需求 (Functional Requirements)
  2. 非功能需求 (Non-Functional Requirements)
  3. 用户故事 (User Stories)
  4. 验收标准 (Acceptance Criteria)
  5. 优先级排序 (P0/P1/P2)
  - 来源: builtin

## 常见错误

- **过度分析**: 用户反馈：简单需求不需要过多分析，保持简洁
  - 频率: 3

## 成功模式

- **结构化输出**: 使用表格和分层标题的分析更容易被用户接受
  - 置信度: 0.9
